# React Component Standard
- Use functional components with Tailwind CSS for styling.
- Prioritize accessibility (ARIA labels, keyboard navigation).
- Implement strict prop-typing or TypeScript for component interfaces.
- Use a "Composition" pattern for complex UI elements.
- Optimize for performance: use `useMemo` and `useCallback` where necessary.
- Ensure responsive design (mobile-first) for all e-commerce surfaces.
